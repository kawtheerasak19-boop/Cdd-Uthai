CDD Uthai Report — ระบบรายงานประจำเดือน

กลุ่มงานสารสนเทศการพัฒนาชุมชน สำนักงานพัฒนาชุมชนจังหวัดอุทัยธานี

กราฟเปรียบเทียบคะแนนการส่งรายงานรายอำเภอ ()

เกณฑ์คะแนน: 1 รายงาน = 2 คะแนน (คำนวณเฉพาะรายงานที่เปิดส่งในเดือนนี้)

สัดส่วนสถานะการส่งงาน

ประจำเดือน

ตารางสรุปผลการส่งรายงานและคะแนนรายอำเภอ ()

เริ่มต้นเดือนใหม่ที่ 0 งาน — คำนวณตามจำนวนหัวข้อรายงานที่ต้องส่งในเดือนนี้

ความคืบหน้าแยกตาม 4 กลุ่มงานหลัก ()

คลิกที่กลุ่มงานเพื่อเข้าสู่หน้าตารางส่งรายงานและอัปโหลดไฟล์

แดชบอร์ดสรุปคะแนนการส่งงานรายเดือน (มกราคม – ธันวาคม)

ติดตามความก้าวหน้าและคะแนนสะสมรายเดือนของทั้ง 8 อำเภอ (คิดเฉพาะรายงานที่เปิดใช้งานในแต่ละเดือน)

ระบบอนุมัติการส่งงาน, ดาวน์โหลดไฟล์งาน & ให้คะแนนแบบแมนนวล (Manual)

แอดมินจังหวัดสามารถดาวน์โหลดไฟล์ ตรวจอนุมัติ ให้คะแนน หรือกดซ่อน/เพิ่มหัวข้อรายงานของเดือนที่เลือกได้ทันที

📋 ตารางให้คะแนนแบบแมนนวล (เฉพาะหัวข้อที่ต้องส่งในเดือนที่เลือก) — คลิกปุ่ม 2 / 1 / 0 เพื่อให้คะแนนได้ทันที

📑 ตารางตรวจสอบ, ดาวน์โหลดไฟล์งานจาก Google Drive และอนุมัติการส่งรายงาน

🗂️ จัดการหัวข้อการรายงาน 4 กลุ่มงาน & กำหนดการเปิด/ซ่อนรายงานประจำเดือน (เฉพาะ Admin)

สามารถเพิ่มหัวข้อการส่งงานใหม่ แก้ไขชื่อ หรือกดซ่อน/ไม่ต้องส่งรายงานบางตัวในแต่ละเดือนได้อิสระ

💡 วิธีใช้งานการซ่อน/เปิดรายงานรายเดือน: เดือนไหนที่มีงานส่งเท่าเดิมไม่ต้องปรับอะไร หากเดือนถัดไปไม่ต้องส่งงานตัวไหน ให้คลิกปุ่ม 🙈 ซ่อนเดือนนี้ หรือคลิกที่ชื่อเดือนในตารางด้านล่างเพื่อเปลี่ยนเป็นสถานะงดส่ง และหากเดือนถัดไปมีการเพิ่มหัวข้อส่งงานใหม่ สามารถกดปุ่ม "➕ เพิ่มหัวข้อรายงานใหม่" ได้ทันที

➕ เพิ่มและจัดการไอดีไลน์ (LINE ID / Group ID)

กำหนดไอดีไลน์สำหรับรับแจ้งเตือน (ระบุเพิ่มเติมภายหลังได้ตลอดเวลา)

📢 แจ้งเตือนทาง LINE ภายหลังจากอนุมัติรายงาน (เฉพาะ Admin)

ส่งแจ้งเตือนเข้า LINE อัตโนมัติผ่าน Google Apps Script หรือแชร์ผ่านแอป LINE ทันที

กลุ่มงาน

ตารางส่งรายงานประจำเดือน อัปโหลดไฟล์เข้า Google Drive แยกตามกลุ่มงาน (ไม่เกิน 5 MB) และดาวน์โหลดไฟล์สำหรับ Admin

📥 นำเข้าข้อมูลการส่งรายงานประจำเดือนด้วย Excel / Google Sheets

เฉพาะแอดมินระดับจังหวัด (Admin) เท่านั้น และต้องยืนยันรหัสลับก่อนนำเข้าข้อมูลหรือรีเซ็ตระบบ

🔐 ระบบป้องกันความปลอดภัยระดับจังหวัด: การนำเข้าข้อมูลด้วยไฟล์ Excel และการรีเซ็ตข้อมูลเป็นค่าเริ่มต้น อนุญาตให้เฉพาะ Admin จังหวัด เท่านั้น และต้องกรอกรหัสผ่านชั้นที่ 2 ก่อนดำเนินการทุกครั้ง
📊

คลิกเพื่อเลือกไฟล์ Excel (.xlsx, .csv) หรือลากไฟล์มาวางที่นี่

ระบบจะขอรหัสยืนยันความปลอดภัยก่อนนำเข้าข้อมูลการส่งรายงานประจำเดือน

🔗 เชื่อมต่อ Google Apps Script, Google Drive & LINE Messaging API (เฉพาะ Admin จังหวัด)

เมื่อใส่ Web App URL แล้ว ทุกไฟล์ที่อำเภออัปโหลดจะถูกจัดเก็บใน Google Drive แยกเป็น 4 โฟลเดอร์ตามกลุ่มงานอัตโนมัติ

➕ เพิ่มหัวข้อการรายงานใหม่ (เฉพาะ Admin)

📤 ส่งรายงานประจำเดือน & อัปโหลดไฟล์งาน

📁 คลิกเพื่อเลือกไฟล์แนบ (ทุกนามสกุล ≤ 5 MB)
ไฟล์จะถูกจัดเก็บเข้าโฟลเดอร์กลุ่มงานใน Google Drive อัตโนมัติ

🔐 ยืนยันรหัสความปลอดภัยแอดมินจังหวัด

กรุณากรอกรหัสยืนยันสำหรับแอดมินระดับจังหวัดเพื่อดำเนินการต่อ
