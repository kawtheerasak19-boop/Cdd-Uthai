แก้ไขข้อมูลทีละอำเภอ แยกตามประเภทการจัดเก็บ และคำนวณเปอร์เซ็นต์โดยอัตโนมัติ

แบบฟอร์มข้อมูลการจัดเก็บ

กรอกเป้าหมายและผลจัดเก็บ หรือปรับเปอร์เซ็นต์โดยตรงเพื่อคำนวณผลการจัดเก็บโดยประมาณ

กรอกยอดครัวเรือนที่รอตรวจสอบ แยกจากยอดจัดเก็บและเป้าหมาย ไม่ถูกนำไปบวกในการคำนวณเปอร์เซ็นต์ (เฉพาะ จปฐ.)
👥 ความคืบหน้าการตรวจสอบประชากรซ้ำ (เฉพาะ จปฐ.)

คำนวณโดยอัตโนมัติ ไม่เกี่ยวกับเปอร์เซ็นต์จัดเก็บ จปฐ.

  1. เลือกเมนู จปฐ. หรือ กชช. 2ค และเลือกอำเภอที่ต้องการบันทึก
  2. กรอกจำนวนเป้าหมายและจำนวนจัดเก็บ หรือกรอกเปอร์เซ็นต์เพื่อคำนวณจำนวนโดยประมาณ
  3. สำหรับ จปฐ. กรอกครัวเรือนรอตรวจสอบ และเป้าหมาย/ผลตรวจสอบประชากรซ้ำเพิ่มเติม (ไม่ส่งผลต่อเปอร์เซ็นต์การจัดเก็บ)

⬇ ดาวน์โหลดแบบฟอร์ม Excel

1. เลือกไฟล์ Excel

รองรับ รายงานความคืบหน้าความจำเป็นพื้นฐาน จปฐ. จากระบบราชการโดยตรง (ชีต Table, หัวตารางแถว 4) และแบบฟอร์มเดิมสำหรับ กชช. 2ค/ตัวชี้วัดที่ตก ระบบจะใช้ ผลการจัดเก็บสุทธิ จากรายงานเป็นยอดคำนวณเปอร์เซ็นต์

ระบบอ่านไฟล์ภายในเบราว์เซอร์ ไม่ส่งไฟล์ต้นฉบับขึ้นเซิร์ฟเวอร์ โดยส่งเฉพาะข้อมูลสรุปที่ตรวจสอบแล้ว

ข้อมูลที่นำเข้าได้

  1. ความคืบหน้า: เลือก จปฐ. หรือ กชช. 2ค กรอกเป้าหมายและยอดจัดเก็บของแต่ละอำเภอ
  2. จปฐ. เพิ่มเติม: ครัวเรือนรอตรวจสอบ จำนวนประชากรซ้ำทั้งหมด และตรวจสอบแล้ว
  3. ตัวชี้วัดที่ตก: กรอกหมายเลข 1–38 และจำนวนไม่ผ่านรายอำเภอ (0 = รายงานว่าไม่พบปัญหา)
  4. ตรวจสอบก่อนส่ง: เว็บจะแสดงจำนวนแถวและตัวอย่างที่กำลังจะอัปเดต แล้วจึงกดยืนยัน
⚠️ ระบบนี้ไม่ใช้ PIN ตามที่กำหนด ผู้ที่ทราบ Web App URL และเข้าถึงได้อาจแก้ข้อมูล จึงควรจำกัดการเผยแพร่ลิงก์ ห้ามนำเข้ารายชื่อหรือข้อมูลส่วนบุคคล

2. ตรวจสอบก่อนบันทึก

ประเภทอำเภอรายละเอียดที่จะบันทึก

⚙️ ตรวจสอบการเชื่อมต่อ Google Apps Script

เว็บทุกเครื่องใช้ URL กลางเดียวกันที่กำหนดอยู่ในไฟล์ index.html

Google Apps Script ที่ใช้เป็นฐานข้อมูลกลาง

ฝังลิงก์ Web App ลงในเว็บไซต์แล้ว ไม่ต้องใช้ไฟล์ config.js หรือกรอกลิงก์ใหม่ในแต่ละเครื่อง

ระบบใช้ลิงก์นี้เสมอ แม้เครื่องนั้นเคยบันทึกลิงก์เก่าไว้ หากต้องการเปลี่ยนภายหลัง ให้แก้ค่า DEFAULT_API_URL ใน index.html แล้วอัปโหลดไฟล์ใหม่บน GitHub
หากเชื่อมต่อไม่สำเร็จ ให้ตรวจสอบว่า Google Apps Script ที่ URL นี้ Deploy เป็น Web App รุ่นล่าสุด และบัญชีผู้ Deploy ได้รัน setupProject พร้อมกำหนด EDIT_PASSWORD ใน Script Properties แล้ว

สถานะระบบ

กำลังตรวจสอบข้อมูลออนไลน์

วิธีดูข้อมูลตรงกันทุกเครื่อง

  1. อัปโหลด index.html รุ่นใหม่นี้ไปแทนไฟล์เดิมบน GitHub Pages
  2. ไม่ต้องอัปโหลด config.js อีกต่อไป (ลบไฟล์เก่าออกได้)
  3. เปิดเว็บไซต์บนอุปกรณ์อื่น แล้วกด Ctrl + F5 เพื่อโหลดไฟล์ล่าสุด
  4. ตรวจสอบสถานะฐานข้อมูลและรุ่นข้อมูลว่าตรงกัน โดยเว็บดึงยอดใหม่ทุก 30 วินาที
ℹ️ การฝังลิงก์ในหน้าเว็บช่วยให้ทุกเครื่องใช้ Google Apps Script ปลายทางเดียวกัน หากเปลี่ยน Deploy ให้พยายามอัปเดต deployment เดิมเพื่อรักษา URL และใช้ Google Sheets เดิม
