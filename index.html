✏️ บันทึกความคืบหน้ารายอำเภอ

แก้ไขข้อมูลทีละอำเภอ แยกตามประเภทการจัดเก็บ และคำนวณเปอร์เซ็นต์โดยอัตโนมัติ

แบบฟอร์มข้อมูลการจัดเก็บ

กรอกเป้าหมายและผลจัดเก็บ หรือปรับเปอร์เซ็นต์โดยตรงเพื่อคำนวณผลการจัดเก็บโดยประมาณ

กรอกยอดครัวเรือนที่รอตรวจสอบ แยกจากยอดจัดเก็บและเป้าหมาย ไม่ถูกนำไปบวกในการคำนวณเปอร์เซ็นต์ (เฉพาะ จปฐ.)
ปรับเปอร์เซ็นต์ได้โดยตรง ระบบจะคำนวณจำนวนที่จัดเก็บตามเป้าหมาย (ปัดเป็นจำนวนเต็ม)

แนวทางบันทึกข้อมูล

  1. เลือกเมนู จปฐ. หรือ กชช. 2ค และเลือกอำเภอที่ต้องการบันทึก
  2. กรอกจำนวนเป้าหมายและจำนวนจัดเก็บ หรือกรอกเปอร์เซ็นต์เพื่อคำนวณจำนวนโดยประมาณ
  3. สำหรับ จปฐ. กรอกจำนวน “ครัวเรือนรอตรวจสอบ” เพิ่มเติม (ไม่ส่งผลต่อเปอร์เซ็นต์การจัดเก็บ)
  4. ระบุ PIN แล้วกดบันทึก เมื่อระบบอ่านกลับจาก Google Sheets สำเร็จ ข้อมูลทุกเครื่องจะเห็นตรงกัน
🔒 บันทึกเฉพาะข้อมูลสรุปรวมระดับอำเภอ ไม่ควรใส่ข้อมูลส่วนบุคคลหรือรายละเอียดครัวเรือนลงในแดชบอร์ดสาธารณะ

⚙️ จัดการการเชื่อมต่อ Google Apps Script

เปลี่ยนลิงก์ Web App ได้จากหน้าเว็บ โดยไม่ต้องเปิดแก้โค้ด index.html

ลิงก์ Web App สำหรับดึงและบันทึกข้อมูล

หลังวางโค้ด Code.gs และ Deploy ให้คัดลอกลิงก์ที่ลงท้าย /exec มาใส่ที่นี่

ลิงก์จะถูกจดจำในเบราว์เซอร์นี้ และเว็บไซต์จะดึงข้อมูลอัตโนมัติเมื่อเปิดอีกครั้ง

สถานะระบบ

ยังไม่ได้เชื่อมต่อข้อมูลออนไลน์

วิธีเชื่อมต่อ Google Sheets

  1. เปิด script.google.com สร้างโปรเจกต์ใหม่ แล้วนำโค้ดในไฟล์ Code.gs ไปแทนที่
  2. รันฟังก์ชัน setupProject หนึ่งครั้ง เพื่อสร้าง Google Sheets สำหรับข้อมูลทั้ง 8 อำเภอ
  3. ไปที่ Project Settings → Script Properties เพิ่มชื่อ ADMIN_PIN และตั้งค่า PIN ที่ต้องการ
  4. กด Deploy → New deployment → Web app เลือก Execute as: Me และ Who has access: Anyone
  5. คัดลอก URL /exec แล้วมาบันทึกในเมนูนี้
ℹ️ เมื่อติดตั้งเวอร์ชันใหม่ของ Apps Script ให้ใช้ URL ของ deployment ปัจจุบัน หากใช้ GitHub Pages ควรตั้งค่าลิงก์ให้ทุกเครื่องที่ใช้งาน หรือกำหนดค่าเริ่มต้นใน DEFAULT_API_URL ของไฟล์ HTML
